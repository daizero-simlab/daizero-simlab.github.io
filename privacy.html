プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-11-21

対象 / Scope

daizero-simlab publisher（以下「本ツール」）は、YouTube チャンネル「第零シミュレーション実験室」の運営者だけが、自分のチャンネルを操作するために使う個人用のツールです。

daizero-simlab publisher ("the tool") is a private tool used solely by the operator of the YouTube channel "第零シミュレーション実験室" to operate that channel.

取得する情報と使い方 / Data accessed and how it is used

本ツールは YouTube API Services を使い、運営者が許可した運営者自身の YouTube アカウントに対してだけ、動画のアップロード、タイトル・説明・サムネイル・公開設定の変更、処理状況の確認を行います。運営者以外の人の情報は取得しません。取得した情報を第三者に提供・販売しません。

The tool uses YouTube API Services only on the operator's own YouTube account, as authorized by the operator, to upload videos, set titles, descriptions, thumbnails and privacy status, and check processing status. It does not collect information from anyone else, and it does not share or sell any data to third parties.

保存 / Storage

認証のトークンは運営者のコンピューターの中だけに保存されます。運営者は Google のセキュリティ設定（https://myaccount.google.com/permissions）からいつでもアクセスを取り消せます。

Authorization tokens are stored only on the operator's own computer. Access can be revoked at any time at https://myaccount.google.com/permissions.

YouTube と Google / YouTube and Google

本ツールは YouTube API Services を使用しています。YouTube 利用規約 / YouTube Terms of Service、Google プライバシーポリシー / Google Privacy Policy も適用されます。
